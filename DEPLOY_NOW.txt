🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If git push fails:
  1. git remote -v (verify origin is set)
  2. git config --list (check git config)
  3. Try: git push origin main

If Vercel build fails:
  1. Check: https://vercel.com/quickweds (logs)
  2. Run locally: npm run build
  3. Check types: npx tsc --noEmit

If site doesn't update:
  1. Hard refresh: Ctrl+Shift+F5 (Windows)
  2. Clear cache
  3. Wait 5-10 minutes
  4. Test in incognito window

If mobile issues:
  1. Clear browser cache
  2. Test on different device
  3. Check Chrome DevTools responsive mode
  4. See DEPLOYMENT_GUIDE.md for more
