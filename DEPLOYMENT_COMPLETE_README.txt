🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Git Push Fails?
  → git remote -v (check remote)
  → git config --list (check config)
  → See DEPLOYMENT_GUIDE.md

Vercel Build Fails?
  → Check: https://vercel.com/quickweds (logs)
  → Run: npm run build (locally)
  → See DEPLOYMENT_GUIDE.md

Site Doesn't Update?
  → Hard refresh: Ctrl+Shift+F5 (Windows) or Cmd+Shift+R (Mac)
  → Wait 5-10 minutes
  → Clear browser cache

Mobile Issues?
  → Clear cache and refresh
  → Test on different device
  → Check Chrome DevTools
  → See DEPLOYMENT_GUIDE.md for more
