## ⚠️ TROUBLESHOOTING

### If Push Fails
```bash
# Check remote
git remote -v

# Try again with verbose
git push -u origin main --verbose

# Check git configuration
git config --list
```

### If Build Fails on Vercel
1. Check Vercel dashboard logs
2. Verify all dependencies installed
3. Check for TypeScript errors: `npm run build`
4. Verify environment variables set

### If Site Doesn't Update
1. Hard refresh browser: `Ctrl+Shift+F5` or `Cmd+Shift+R`
2. Clear browser cache
3. Wait 5-10 minutes for DNS propagation
4. Test in incognito/private window

### If Mobile Issues Persist
1. Check Chrome DevTools (responsive mode)
2. Test with real device
3. Check for console errors
4. Verify viewport meta tag in layout.tsx
5. Check for horizontal scroll in responsive mode
