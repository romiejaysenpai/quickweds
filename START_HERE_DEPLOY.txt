================================================================================
TROUBLESHOOTING - IF SOMETHING GOES WRONG
================================================================================

❌ "git push" fails?
   → Run: git remote -v (check if origin is set)
   → Try: git push origin main (without -u)

❌ Vercel build fails?
   → Visit: https://vercel.com/quickweds (check logs)
   → Run locally: npm run build

❌ Site doesn't update?
   → Hard refresh: Ctrl+Shift+F5 (Windows) or Cmd+Shift+R (Mac)
   → Wait 5-10 minutes for DNS cache to clear
   → Try in private/incognito window

❌ Mobile still has issues?
   → This shouldn't happen (all fixed!)
   → Clear browser cache
   → Test on different browser
   → See DEPLOYMENT_GUIDE.md for more
