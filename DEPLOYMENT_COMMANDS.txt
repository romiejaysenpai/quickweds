================================================================================
TROUBLESHOOTING
================================================================================

Q: Git push fails - what should I do?
A: Check:
   1. git remote -v (verify origin is set)
   2. git config --global user.name (verify your name)
   3. git config --global user.email (verify your email)
   4. Try: git push origin main (without -u flag)

Q: Vercel build fails - what should I do?
A: Check:
   1. Vercel dashboard logs: https://vercel.com/quickweds
   2. Run locally: npm run build
   3. Check for TypeScript errors: npx tsc --noEmit
   4. Verify environment variables are set

Q: Site doesn't update after deployment
A: Try:
   1. Hard refresh browser: Ctrl+Shift+F5 (Windows) or Cmd+Shift+R (Mac)
   2. Clear browser cache
   3. Wait 5-10 minutes for DNS cache to clear
   4. Test in private/incognito window

Q: Mobile page still has horizontal scroll
A: This shouldn't happen - all 17 scroll issues are fixed!
   But if it does:
   1. Clear browser cache
   2. Hard refresh
   3. Test in different browser
   4. Check Chrome DevTools responsive mode

Q: Countdown timer not showing
A: All 24 templates have it - but verify:
   1. You're on a wedding landing page (not homepage)
   2. Wedding date is set correctly
   3. Try a different template
   4. Check browser console for errors
