## What Happens After Push

1. **GitHub receives push** (30 seconds)
2. **Vercel detects change** (1 minute)
3. **Build starts** (1-2 minutes)
   - Installs dependencies
   - Builds Next.js app
   - Runs ESLint checks
4. **Deployment completes** (1-3 minutes)
5. **App goes live** at https://www.quickweds.site/

**Total time: 3-5 minutes**

## Quick Troubleshooting

**If build fails:**
- Check https://vercel.com/quickweds/quickweds/deployments for error logs
- Common fixes:
  - Clear .next folder and retry
  - Check for TypeScript errors: `npm run build` locally
  - Verify all imports are correct

**If deployment is slow:**
- Normal for first deployment after changes
- Check Vercel analytics: https://vercel.com/quickweds/quickweds

**To check locally before deploying:**
```bash
npm run build
npm run dev
```
Then visit http://localhost:3000
